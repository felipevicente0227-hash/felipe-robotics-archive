# 2021 Korea Champion — Autonomous Patient Transfer Robot

Line-tracing autonomous robot that transports a patient figure between stations on a marked course. Built for the Korea RoboSTEAM competition, 2021.

## Files

- `korea - automatic Patient Transfer Robot/` — six block-editor programs (`.bpd`). These are binary files from a block-based programming environment and cannot be read as text; the specific editor they belong can be downlanded from 'https://www.artec-kk.co.jp/studuino/en/studuino.php'
  
  - `Felipe_Korea.bpd`, `Korea RoboSTEAM.bpd` — main programs
  - `FCB_UPside 0207.bpd` / `FCB_UPside 0220a.bpd`, `FCB_down0207.bpd` / `FCB_down0220A.bpd` — upper and lower mechanism programs, in dated revisions (7 Feb and 20 Feb)
- `korea championship robot map line tracing.mp4` — line tracing over the course map
- `korea championship robot trial 2.mp4` — competition trial run
- 8 build photographs (January 2021)

## Tested conditions & limitations

**Hardware disassembled — the behaviour described here is documented from the competition videos and build photographs in this folder, not from a live re-test.** The programs are stored in a binary block-editor format, and can be opened through the studuino bit prodram

The controller platform and sensor kit, the line colour and surface, and the number of line sensors were not saved, and cannot be recovered from the binary program files. Known failure modes were not written down at the time. Course length, run times, success rate and payload mass were not recorded either, and the hardware no longer exists to re-measure them.

The two dated revisions of each mechanism program (0207 → 0220) show the logic was retuned between those dates; what specifically changed is not recorded.
